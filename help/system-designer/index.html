System Designer

What it does

AVTools System Designer is a Revit add-in for designing, analyzing and documenting distributed ceiling loudspeaker systems. It runs as a dockable panel inside Revit 2025 and 2026, places loudspeakers in the host model, and reads rooms from the host or from linked architectural models. It works from Floor Plan or Reflected Ceiling Plan views.

How to open it

Revit ribbon: BIM Acoustics tab → AV Tools panel → System Designer.

The workflow

The panel is a step-by-step workflow, one tab per step:

  1. Rooms — pick which rooms are in design scope. Always first. Click Rescan Rooms to list rooms from the host model and every loaded link (the Source column shows which file each came from). Add Temp Room handles spaces with no Revit room or an unbounded one.
  2. Configuration — set host mode, spacing, listener height, layout and speaker selection per room. Run Refresh Calculations, then Commit Placement.
  3. Direct-Field Coverage — Compute Results for SPL uniformity from the placed speakers; optionally Draw Iso-Map.
  4. Room Acoustics — surfaces are found with the Room Exchange engine; assign acoustic materials, then calculate RT60 (Sabine, Norris-Eyring, Arau-Puchades) and estimated STI. Refresh re-reads the rooms after you change the model.
  5. Circuiting (Pro) — assign circuit IDs, zones, taps and modes (70V / 100V / Low-Z); generates the JSBA Loudspeaker Circuit Schedule.
  6. Amps & Cabling (Pro) — rack discovery, nearest-rack assignment, wire gauge, line loss, wiring diagrams.
  7. Coordination (Pro) — clash detection between AV devices and MEP, lighting and structural elements.
  8. About — version, transcript opt-in and support tools. The subscription itself is in License Manager.

Remove Selected Rooms takes rooms out of scope and removes what AVTools placed for them; Reset All Design State does the same for the whole project, after showing what it will remove and asking first. Revit Undo reverses both.

Plans

Free v1.2.1 (Revit 2022–2024): layout, placement and coverage. Standard adds room acoustics. Pro adds circuiting, amps & cabling, coordination, SpecTool and Room Exchange. The 14-day trial unlocks every Pro feature. Lucius and SpecTool need an internet connection; everything else works offline once the license is activated.

System Designer

What it does

AVTools System Designer is a Revit add-in for designing, analyzing and documenting distributed ceiling loudspeaker systems. It runs as a dockable panel inside Revit 2025, 2026 and 2027, places loudspeakers in the host model, and reads rooms from the host or from linked architectural models. It works from Floor Plan or Reflected Ceiling Plan views.

How to open it

Revit ribbon: BIM Acoustics tab → AV Tools panel → System Designer.

The workflow

The panel is a step-by-step workflow, one tab per step:

  1. Rooms — pick which rooms are in design scope. Always first. Click Rescan Rooms to list rooms from the host model and every loaded link (the Source column shows which file each came from). Add Temp Room handles spaces with no Revit room or an unbounded one.
  2. Configuration — set host mode, spacing, listener height, layout and speaker selection per room. Run Refresh Calculations, then Commit Placement.
  3. Direct-Field Coverage — Compute Results for SPL uniformity from the placed speakers; optionally Draw Iso-Map, with a 1, 2 or 3 dB iso-line step and optional band fill.
  4. Room Acoustics — surfaces are found with the Room Exchange engine; assign acoustic materials, then calculate RT60 (Sabine, Norris-Eyring, Arau-Puchades), estimated STI (MTF), then map STI over each room with the STI Map section. Refresh re-reads the rooms after you change the model. Export PNG saves the RT60 graph as an image.
  5. Circuiting (Pro) — assign circuit IDs, zones, taps and modes (70V / 100V / Low-Z); generates the JSBA Loudspeaker Circuit Schedule.
  6. Amps & Cabling (Pro) — rack discovery, nearest-rack assignment, wire gauge, line loss, wiring diagrams.
  7. Coordination (Pro) — clash detection between AV devices and MEP, lighting and structural elements.
  8. About — version, transcript opt-in and support tools. The subscription itself is in License Manager.

Remove Selected Rooms takes rooms out of scope and removes what AVTools placed for them; Reset All Design State does the same for the whole project, after showing what it will remove and asking first. Revit Undo reverses both.

SPL map settings

On Direct-Field Coverage, the row under the buttons sets how Draw Iso-Map draws the SPL map; the settings are saved with the project.

  • SPL iso-line step — 1, 2 or 3 dB between the SPL lines, down to 6 dB below the room's reference level. 2 dB is the default. The table's bands do not change.
  • Fill bands and Transparency % — semi-transparent colour bands between the iso-lines, pale yellow (best) to dark brown (worst), readable in black-and-white print. Off by default; 60 % transparency.

STI map

The STI Map section is on the Room Acoustics tab, below Critical Distance & D/R Ratio, because STI needs that tab's results. For each room: assign materials, run Calculate, then Compute STI Map and Draw STI Map (in the active plan view). STI is calculated at every point the SPL map samples, from the direct field of the room's loudspeakers plus the room's reverberant field and background noise, per octave band from 125 Hz to 8 kHz, with the IEC 60268-16 male weighting; the RT comes from the formula chosen as the STI Basis.

  • Iso-lines every 0.05 STI, labelled, in detail groups named JSBA_STI_…, separate from the SPL map's JSBA_DFM_… so both can be on the plan. Clear STI Map removes only STI maps.
  • Target STI — 0.60 by default; sets the table's “% ≥ Target” and the heavier target line. Compute STI Map again after changing it.
  • Fill bands and Transparency % — the same colour bands, set separately for the STI map.
  • The table gives min, average and max STI, the share of the floor at or above the target, and the STI at the room's reference position, which equals the STI (MTF) column. A room without an STI map says why in the Note column. The figures also go to the JSBA Room Acoustics Schedule and the Room Acoustics CSV.

Plans

Free v1.2.1 (Revit 2022–2024): layout, placement and coverage. Standard has layout and coverage on Revit 2025–2027. Pro adds room acoustics (RT60, STI), circuiting, amps & cabling, coordination, SpecTool and Room Exchange. The 14-day trial unlocks every Pro feature.
